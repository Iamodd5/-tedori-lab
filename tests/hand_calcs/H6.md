# H6 — pensioner couple, both 72, public pensions 2,000,000 and 800,000

**Income.** Age 65+: pension 2,000,000 is over 1,100,000 and under 3,300,000 → 2,000,000 − 1,100,000 = **900,000**. Pension 800,000 ≤ 1,100,000 → **0**.

**National Health Insurance (Shinjuku, FY2026).** Base: 900,000 − 430,000 = 470,000 and 0.
Reduction test: household income 900,000 − 150,000 (65+ pension extra) = 750,000. Earners (給与所得者等) = 1: the head's pension 2,000,000 is over 1,250,000; the spouse's 800,000 is not (see revision below) → base limit 430,000. 70% limit 430,000 < 750,000; 50% limit = 430,000 + 310,000 × 2 = 1,050,000 → 750,000 ≤ 1,050,000 → per-member amounts cut by 50%.
- Medical: 47,600 × 2 × 0.5 + 470,000 × 7.51% = 47,600 + 35,297 = 82,897
- Support: 17,600 × 2 × 0.5 + 470,000 × 2.80% = 17,600 + 13,160 = 30,760
- Child-support: 1,873 × 2 × 0.5 + 470,000 × 0.27% = 1,873 + 1,269 = 3,142
- Total **116,799** (no LTC part: both over 64)

**Income tax.** 900,000 − 1,040,000 < 0 → 0 for both.

**Resident tax.** Head: one family member (spouse, income 0 ≤ 620,000) → per-capita limit 350,000 × 2 + 310,000 = 1,010,000 ≥ 900,000 → 0. Spouse: income 0 → 0.

**Disposable income** = 2,800,000 − 116,799 = **2,683,201** (long-term-care premium for 65+ not included, Q15)

**Revision 2026-11-03 (who counts as an earner in the NHI reduction test, OPEN_QUESTIONS Q25).** 国民健康保険法施行令29条の7第6項第1号
counts a 給与所得者等 only if salary revenue is over 550,000, or (for someone without salary income) public-pension revenue is over
600,000 under age 65 or over 1,100,000 at 65 or over; 附則5条 raises the last figure to 1,250,000 and takes 150,000 off 65+ pension
income (sources/law/kokuho_sekourei_333CO0000000362_asof20260401.xml; Shinjuku's 令和8年度 table says the same,
sources/shinjuku/000452430.pdf p.1). Before this revision every member with any income counted, so H6 had 2 earners and a base limit
of 530,000. The result at the reference pensions does not change (50% cut either way).

It changes the wall map. Head's pension **1,700,000**, spouse 800,000:
- Pension income 1,700,000 − 1,100,000 = 600,000; test income 600,000 − 150,000 = 450,000. Earners = 1.
- 70% limit 430,000 < 450,000; 50% limit 1,050,000 → **50% cut** (with 2 earners the 70% limit was 530,000, so it was a 70% cut).
- Base 600,000 − 430,000 = 170,000. Medical 47,600 × 2 × 0.5 + 170,000 × 7.51% = 47,600 + 12,767 = 60,367; support 17,600 + 4,760 = 22,360;
  child-support 1,873 + 459 = 2,332 → NHI **85,059** (was 58,229 with the 70% cut).
- Taxes: income 600,000 < basic deduction → income tax 0; resident tax: 600,000 ≤ 1,010,000 → 0.
- Disposable income = 1,700,000 + 800,000 − 85,059 = **2,414,941** (was 2,441,771).

**Revision 2026-11-03: long-term-care premiums for people 65 and over (介護保険 第1号), OPEN_QUESTIONS Q15.**
Shinjuku's fiscal 2026 table (sources/shinjuku/file07_02_00006.html, 「65歳以上（第1号被保険者）の方の介護保険料（令和8年度）」, 18 bands,
base 79,200) and 介護保険法施行令38条1項 (sources/law/kaigo_sekourei_410CO0000000412_asof20260401.xml, the 826,500 line). The band is set
from income and resident-tax status before this premium is deducted (in law, the previous year's); the premium is then a social
insurance deduction for its payer.
- Nobody in H6 pays resident tax (above), so both are in bands 1–3 (世帯全員 住民税 非課税), judged on 課税年金収入 + その他の合計所得:

  - spouse: 800,000 + 0 ≤ 826,500 → band 1, **19,800**.
- The deduction changes no tax (both pay none) and not NHI (set on income).
- **Disposable income** = 2,683,201 − 51,480 − 19,800 = **2,611,921**.

Head's pension **1,700,000**: band 3 again (1,700,000 > 1,200,000) and spouse band 1 → 2,414,941 − 71,280 = **2,343,661**.
