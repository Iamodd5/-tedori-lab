# H6 — pensioner couple, both 72, public pensions 2,000,000 and 800,000

**Income.** Age 65+: pension 2,000,000 is over 1,100,000 and under 3,300,000 → 2,000,000 − 1,100,000 = **900,000**. Pension 800,000 ≤ 1,100,000 → **0**.

**National Health Insurance (Shinjuku, FY2026).** Base: 900,000 − 430,000 = 470,000 and 0.
Reduction test: household income 900,000 − 150,000 (65+ pension extra) = 750,000. Earners = 2 → base limit 430,000 + 100,000 = 530,000. 50% limit = 530,000 + 310,000 × 2 = 1,150,000 → 750,000 ≤ 1,150,000 → per-member amounts cut by 50%.
- Medical: 47,600 × 2 × 0.5 + 470,000 × 7.51% = 47,600 + 35,297 = 82,897
- Support: 17,600 × 2 × 0.5 + 470,000 × 2.80% = 17,600 + 13,160 = 30,760
- Child-support: 1,873 × 2 × 0.5 + 470,000 × 0.27% = 1,873 + 1,269 = 3,142
- Total **116,799** (no LTC part: both over 64)

**Income tax.** 900,000 − 1,040,000 < 0 → 0 for both.

**Resident tax.** Head: one family member (spouse, income 0 ≤ 480,000) → per-capita limit 350,000 × 2 + 310,000 = 1,010,000 ≥ 900,000 → 0. Spouse: income 0 → 0.

**Disposable income** = 2,800,000 − 116,799 = **2,683,201** (long-term-care premium for 65+ not included, Q15)
