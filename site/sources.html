数字を再現する手順（専門的な内容）How to rebuild every number (for specialists)

Python 3.11 と Node.js が必要です。

Needs Python 3.11 and Node.js.

uv venv --python 3.11 .venv && VIRTUAL_ENV=.venv uv pip install -r requirements.txt
make all

この手順を実行すると、使った資料が sources/ フォルダーにそろいます。資料ごとにハッシュ値（SHA-256）を記録してあり、改変がないことを確かめられます。ハッシュ値は、ファイルが変わっていないことを確かめるための値です。協会けんぽのウェブページ3つは、ダウンロードのたびにファイルが変わるため、確かめる対象から除いています。

After the build, every source document is in sources/ with a checksum (SHA-256), a value that shows whether a file has changed, so anyone can check that it has not. The exception is three web pages of the Japan Health Insurance Association, whose file differs on every download.

下の「すべての資料の一覧」は、使った資料を一つずつ挙げた表です。説明は英語ですが、資料の題名は日本語のままで、発行元のURLも載せています。表の見出しは、File がファイル名、Title が題名、Published が公表日、Pages がページ数、Status が入手の状況、Used for が使いみちです。Status の downloaded は入手済み、landing page only は入口のページだけ入手済み、MISSING は入手できなかったという意味です。The list in the section that follows gives every document used, one row each, with its title as published, the publisher's URL and whether the file has been downloaded.
