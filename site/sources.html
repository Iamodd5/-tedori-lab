すべての数字は、リポジトリを取得して次のコマンドで作り直せます（Python 3.11 が必要）。

Every number can be rebuilt from a fresh copy of the repository with these commands (needs Python 3.11):

uv venv --python 3.11 .venv && VIRTUAL_ENV=.venv uv pip install -r requirements.txt
make all

使った資料はすべて sources/ に保存し、指紋（SHA-256）で改変がないことを確かめられます。以下の一覧は英語です。

Every source document is saved in sources/ with a SHA-256 fingerprint so anyone can check it has not changed.
